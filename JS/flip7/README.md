# Flip7 (simplifié) - Mode texte (Node.js)

Jeu de cartes multi-joueurs en console inspiré de Flip7, version simplifiée.
- n joueurs (2 à 8)
- clavier partagé
- toutes les actions sont enregistrées dans un fichier `logs/*.jsonl`

## Prérequis
- Node.js (version récente)

## Lancer le jeu
```bash
npm install
npm start
